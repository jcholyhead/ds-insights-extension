Privacy Policy

Dreaming Insights Extension — Chrome Web Store

This extension does not transmit any data off your device. All data captured and stored by this extension remains entirely local to your browser.

What this extension does

The Dreaming Insights Extension intercepts specific API responses made by app.dreaming.com while you browse your progress page, and makes that data available to you within the extension popup and on the dreaminginsights.com website.

What data is accessed

The extension reads the JSON responses from three API endpoints on app.dreaming.com:

  • watchedVideo — information about videos you have watched
  • externalTime — information about externally tracked learning time
  • dayWatchedTime — a historical record of daily watch time

This data is data you have already generated through your own activity on app.dreaming.com. The extension reads responses that your browser has already received from that site's servers.

How data is stored

Captured responses are stored using chrome.storage.local — Chrome's built-in local storage mechanism for extensions. This storage is:

  • Stored only on your device
  • Never synced to any server or cloud service
  • Accessible only by this extension
  • Clearable at any time using the Clear button in the extension popup

Data transmission

This extension does not send any data to any external server, analytics service, or third party of any kind. There are no network requests initiated by this extension beyond those already made by the websites you visit.

Permissions used and why

  • storage — to persist the most recent API responses in chrome.storage.local so they are available when you open the popup or visit dreaminginsights.com.
  • Host permission for app.dreaming.com — to inject the content script that intercepts API responses on your progress page.
  • Host permission for dreaminginsights.com — to inject the script that detects the extension is installed and auto-fills data fields on that site.

Websites the extension runs on

  • app.dreaming.com/spanish/progress — to capture API responses
  • dreaminginsights.com and www.dreaminginsights.com — to signal that the extension is installed and to fill data fields

The extension does not run on any other websites.

Data retention

Data is retained in local storage until you clear it via the extension popup, uninstall the extension, or clear your browser's extension storage. No data is retained anywhere else.

Contact

If you have questions about this privacy policy or how the extension works, please contact us via dreaminginsights.com.
